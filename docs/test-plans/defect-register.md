# Manual test plan: the defect register (Excel)

Device: iPad [model], iPadOS [version]
Build/commit:
Tester / date:

Use an inspection with a memo, a few instructions (one with photo confirmation and photos), an observation and a general note. Reply with step numbers and what you saw.

1. **Update.** Accept the update and check Settings shows the new commit.
2. **Make it.** Site memo, Export card: under the PDF, **Export defect register**. It shows the file name, e.g. "SY000001-SIM001-A-Level 3 slab - Defect register.xlsx".
3. **Share.** **Share register…**: the Share sheet opens; save it to Files.
4. **Open it.** Open it in Excel (or Numbers / Files preview): job details at the top, then the table: instructions IA, IB…, then observations OA… (general notes say "General note", Drawing and Sheet "All"), photo confirmation Yes/No, photo refs IA1, IA2… matching the PDF's photo appendix, then empty Status, Date closed and Comments.
5. **Excel niceties.** On a computer: the header row stays put when scrolling, and has filter arrows.
6. **Offline.** In airplane mode, make the register again: it works.
