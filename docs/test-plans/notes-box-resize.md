# Manual test plan: resizing the notes box

Device: iPad [model], iPadOS [version]
Build/commit:
Tester / date:

Use a page with a few pins (some long instruction text helps). Reply with step numbers and what you saw.

1. **Update.** Accept the update and check Settings shows the new commit.
2. **Select.** Tap the notes box (finger or Pencil): a dashed outline, a round handle on each side, and a small dark **S M L** bar (above the box, or below it when the box is near the top of the sheet).
3. **Narrower / wider.** Drag a side handle in and out: the text re-wraps and the box grows taller or shorter. It stops at a sensible minimum and maximum.
4. **Text size.** Tap **S**, then **L**, then **M**: the text changes size; M is the size it was before this update.
5. **Move.** Drag the box by its middle: it moves as before.
6. **Let go.** Tap the drawing: the handles and bar go.
7. **Undo.** Use Undo (button or two-finger double-tap) a few times: the size, width and move come back one at a time; Redo re-applies them.
8. **Export.** Export the PDF pack: the box on the drawing page has the same width and text size as on screen.
9. **Other pages.** Another page's box is unchanged (each page's box is its own).
10. **Pins still work.** With the Pin tool on, tapping near (not on) the box still places pins.
