# Manual test plan: a whole inspection in airplane mode (step 10e)

Device: iPad [model], iPadOS [version]

Tester / date:

Use a test inspection (synthetic drawing is fine). Reply with step numbers and what you saw.

1. **Update first.** With Wi-Fi on, open the app, accept the update if offered, and check Settings shows the new commit. Fully close the app.
2. **Airplane mode.** Turn on airplane mode (Wi-Fi and mobile data off). Open Hardhat from the Home Screen: it opens normally.
3. **New inspection.** Create a project and inspection, add a drawing from Files, place two pins (one instruction with photo confirmation), draw a pen line, and take a photo.
4. **Pages and zoom.** Open the Pages view, move a page, and zoom into the drawing: it sharpens as usual.
5. **Memo.** Create the memo: the preview shows, with the * lead-in.
6. **Export.** Export the PDF pack, tap **Preview** (zoom in: sharp), then **Share…**, Save to Files.
7. **Back up.** Pre-inspection, **Back up now**, **Share…**, Save to Files.
8. **About.** Settings, About: the User guide opens.
9. **Import.** Delete the test inspection, then import the backup from Files (Inspections, Import): it comes back with its pins, photo and memo.
10. **Back online.** Turn airplane mode off; nothing changes, and no errors appear.
